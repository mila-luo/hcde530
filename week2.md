# Week 2 — Competency 2: Code literacy & documentation

Short write-up for **A2**. *(A longer reflection with the same themes lives in `week2/week2.md`.)*

## Code literacy

I can read a small Python script end to end and explain what it does in plain language—not only run it. This week that meant following how the demo script loads `demo_responses.csv`, walks each row, counts words, and prints a table plus a short summary so I can compare response lengths across participants.

## Documentation

I added `#` comments in **plain English** next to the important parts of `week2/demo_word_count.py` so a classmate could skim the file and see *why* each block exists (loading the CSV, counting words, printing the table, summarizing min/max/average). I also keep a separate markdown reflection in the repo so my competency claim is not buried only inside the code.

## Version control & GitHub

I used Git to save snapshots of my work as it changed, and pushed the project to GitHub so the submission is the repo URL—not a zip. I’m still building habits for *when* to commit, but the work now lives somewhere a grader can open and run against the demo CSV.

## Competency claim (one sentence)

I’m building confidence editing code in Cursor with AI as support, and I’m documenting that work with inline comments, markdown, and a GitHub repo that holds the runnable script and data together.
